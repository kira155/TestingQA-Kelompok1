# Rencana Pembagian Tugas Kelompok

Pembagian di bawah ini merupakan usulan untuk didiskusikan bersama. Nama PIC dan hasil pekerjaan diisi setelah anggota menyepakati tugasnya.

| Anggota | Bagian | Pekerjaan berikutnya | Status |
|---|---|---|---|
| 1 | Login dan hak akses | Uji login benar/salah, daftar akun Staff, logout dan akses Admin | Belum dikonfirmasi |
| 2 | Stok dan permintaan | Uji pencarian, filter, jumlah barang dan alur permintaan | Belum dikonfirmasi |
| 3 | White Box dan transaksi | Cek alur barang masuk/keluar, validasi stok dan lima temuan kode | Belum dikonfirmasi |
| 4 | Dokumentasi dan wawancara | Kumpulkan screenshot, periksa hasil anggota, hubungi narasumber QA | Belum dikonfirmasi |

## Checklist pekerjaan berikutnya

- [ ] Sepakati PIC masing-masing bagian.
- [ ] Siapkan aplikasi dan database uji di XAMPP dengan data dummy.
- [ ] Jalankan ulang test case secara manual dan isi hasil aktual.
- [ ] Cek ulang lima temuan kode; perbaiki bug yang terbukti.
- [ ] Uji ulang fungsi yang berubah dan simpan screenshot.
- [ ] Lakukan wawancara QA dan lengkapi laporan.

## Catatan pekerjaan anggota

| Tanggal | Nama | Test case / file | Hasil atau kendala | Bukti / commit |
|---|---|---|---|---|
| | | | | |

Setiap anggota mengisi catatan sesuai pekerjaan yang benar-benar dilakukan. Commit menggunakan akun GitHub masing-masing apabila anggota sudah menyelesaikan perubahan.
