# SRC-007: CSRF pada form mutasi data

- **Severity potensial:** High (berdasarkan risiko desain; perlu validasi dampak operasional)
- **Status:** PATCHED / RUNTIME NOT VERIFIED
- **Sumber:** `actions/*.php dan forms POST` (review 25 November 2026)
- **Jenis evidence:** inspeksi kode secara statis, bukan bukti eksploitasi atau kegagalan runtime.

## Temuan

Request POST awal tidak memverifikasi token CSRF; session login saja tidak mencegah cross-site request forgery.

## Tindakan yang diusulkan/dilakukan pada salinan source

Guard token untuk aksi mutasi dan hidden token pada form ditambahkan; uji POST dengan/tanpa token di staging.

## Reproduksi dan verifikasi manual

Retest: belum dilakukan. Catat hasil aktual, tanggal, penguji dan bukti pada skenario Black Box atau White Box terkait sebelum menutup temuan.
